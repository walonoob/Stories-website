# Stories Resto & Coffee

A responsive, static restaurant website for Stories in Nairobi. It uses the venue photos from the supplied project brief, embeds a Google Map, and creates WhatsApp table requests for +254 113 444999.

## Preview

Open `index.html` in a browser. The map and Google Fonts need an internet connection; the restaurant photos are stored locally in `assets/`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html`, `README.md`, and the `assets` folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.

The WhatsApp booking form opens a prefilled message; Stories confirms bookings directly in WhatsApp.
